# KPI Calculation Engine (KPI-ENGINE.md)

## 1. Description
The KPI Engine aggregates multi-dimensional measures over arbitrary temporal bounds, translating raw counts into strategic operational indicators.

## 2. Core Initial KPIs
- **SLA Compliance Rate:** Percentage of automation flows completed within SLA targets.
- **Vision Inspection Accuracy:** Average precision score from neural crack detection scans.
- **API Gateway Availability:** Request success ratios across client keys.
- **Consultant Workspace Productivity:** Rate of certified recommendations formulated.
- **Spatial Layout Defect Densities:** Distribution of Vastu warning coordinates on floor plan layers.

## 3. Custom Formulations
Administrators can configure customized equations at runtime using the Dashboard Builder (e.g., `SUCCESS_RUNS / TOTAL_RUNS * 100`) with custom target thresholds and units.
