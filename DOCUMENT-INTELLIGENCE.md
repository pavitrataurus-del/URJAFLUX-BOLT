# DOMAIN-010 — Document Intelligence Features

## Features
- **Automatic Table of Contents**: Generated dynamically from section headers and keys.
- **Section & Page Numbering**: Hierarchical numbering (`1.0`, `2.0`) and page layout control.
- **Cross-Domain References & Citations**: Direct hyperlinking to canonical scripture verses and rule IDs.
- **Figure & Table Captions**: Automated figure labeling for floor plans, telemetry charts, and evidence photos.
- **QR Code Verification**: QR Code embedded in headers and preview modals linking directly to property or digital twin verification URLs.
