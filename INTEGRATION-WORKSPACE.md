# API Gateway Workspace Console (INTEGRATION-WORKSPACE.md)

## 1. Description
The Gateway Workspace Console offers a single unified control center for administrators, security personnel, and enterprise consumers to manage URJAFLUX external interfaces.

## 2. Interactive Navigation Panels
- **Health Dashboard:** Displays charts tracking latency curves, protocol distribution percentages, and rate-limiting triggers.
- **API Playground:** Supports interactive REST and GraphQL schema browser queries using live consumer credentials.
- **Connector Hub:** Displays active external bridges, sync states, and manual synchronization triggers.
- **Webhooks Sync:** Provides subscription forms, manual event publishers, and logs of outbound delivery payloads.
- **Consumer Registry:** Supports consumer company creation, tiered quota allocation, and API key generation/revocation.
- **Import / Export:** Supports validating coordinates sheets, executing pipeline conversions, and downloading data.
- **Interactive Docs:** Presents OpenAPI and GQL specifications cleanly with copyable curl request segments.
- **Log Explorer:** Explores raw incoming transaction records and status codes in chronological order.
