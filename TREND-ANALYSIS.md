# Trend & Anomaly Analysis (TREND-ANALYSIS.md)

## 1. Description
The Trend Analysis Module evaluates multi-week operational variables to surface underlying historical trends and spikes.

## 2. Capabilities
- **Growth Analysis:** Compares start-to-end historical sequences to output precise growth ratios.
- **Seasonality Tracking:** Captures recurring cyclic patterns (e.g. weekday traffic load spikes).
- **Anomaly Detection:** Tracks standard deviation margins. Points straying past 1.8x std deviation are flagged with high-severity anomaly markers on the interactive timeline.
