# Global Search & Discovery Index (SEARCH-DISCOVERY.md)

## 1. Multi-Field Search Querying
The search engine queries across multiple entity index arrays:
- **Discussions:** Titles, descriptions.
- **Comments & Replies:** Message text, authors.
- **Annotations:** Pin text, resource labels.
- **Members:** Email addresses, workspace roles.
- **Attachments:** File names.

## 2. Saved Searches Configuration
Users can save precise search queries and filter parameters into a collection list. These can be re-run with a single click to dynamically reload matching updates.
