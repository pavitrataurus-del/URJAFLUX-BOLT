### Core Architectural Mandates (Immutable)
1. **Unified Workspace:** Navigation is centralized around a dockable spatial/semantic workspace, eliminating fragmented page-hopping.
2. **Performance Constraints:** WebGL and Web Workers are strictly required for Canvas/Graph rendering and physics. Virtualization is required for all substantial lists and grids.
3. **Design System:** Utility-first (Tailwind), supporting Dark, Light, and Compact modes with strict WCAG AA compliance.
4. **Deep Linking & Server Sync:** The UI acts as a resilient view into server-state, supporting deep contextual links and asynchronous background continuity.
