# NAVIGATION-MAP
## URJAFLUX AI OS

### Global Navigation (Left Sidebar)
- **⌂ Dashboard**
- **📁 Projects**
  - Project List
  - Create New
- **🧠 Knowledge Engine**
  - Upload Center
  - Document Library
  - Processing Monitor
- **🏗️ Digital Twin**
  - Spatial Viewer
  - Twin Explorer
- **🕸️ Knowledge Graph**
  - Graph Explorer
  - Ontology Manager
- **🤖 AI Reasoning**
  - Reasoning Console
  - Expert Registry
  - Decision Traces
- **✓ Review & Reports**
  - Human Review
  - Recommendation Center
  - Report Generator
- **⚙️ Administration** (Admin Only)
  - Users & Roles
  - System Health
  - Settings

### Contextual Navigation (Within a Project)
When a user is inside a specific project, the top header displays a breadcrumb (`Projects / Alpha Tower`), and a secondary horizontal tab bar appears:
- **Overview** | **Documents** | **Spatial Canvas** | **Twin Data** | **AI Insights** | **Reports** | **Settings**

### Utility Navigation (Top Right)
- **Command Palette Trigger** (Search Icon / Cmd+K)
- **Background Tasks** (Spinner/Progress Icon)
- **Notifications** (Bell Icon with unread badge)
- **Help/Docs** (Question Mark)
- **User Profile** (Avatar -> Dropdown: Preferences, Logout)
