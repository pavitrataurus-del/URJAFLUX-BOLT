# SCREEN-INVENTORY
## URJAFLUX AI OS

### 1. Authentication & Onboarding
- **Login Screen:** SSO, Email/Password, MFA prompt.
- **Role Selection / Organization Switcher:** For users in multiple orgs.
- **First-Time Setup Wizard:** Initial configuration for admins.

### 2. Primary Navigation (Global)
- **Global Dashboard:** Aggregated metrics across all projects, system health, recent activities.

### 3. Project Management
- **Projects List:** Data grid of all projects with status, client, and timestamps.
- **Create Project Wizard:** Multi-step form (Details -> Connect Data -> Permissions).
- **Project Dashboard:** Overview of a single project's progress and alerts.

### 4. Knowledge Ingestion & Management
- **Upload Center:** Drag & drop interface, queue management, streaming status.
- **Processing Monitor:** Detailed view of active ingestions, pipelines, and error states.
- **Knowledge Library:** Searchable grid/list of all ingested documents and packages.
- **Ontology Explorer:** Hierarchical view of active ontologies and concepts.
- **OCR Viewer:** Split pane showing original document and extracted bounding boxes/text.
- **Embedding Explorer:** Vector visualization and semantic search interface.

### 5. Intelligence & Analysis
- **Spatial Intelligence Viewer:** 2D interactive canvas for floor plans and zoning.
- **Digital Building Twin Viewer:** Advanced viewer combining spatial data with knowledge objects.
- **Knowledge Graph Explorer:** Force-directed graph visualization of extracted entities.

### 6. AI & Reasoning
- **AI Reasoning Console:** Real-time stream of expert engine activities and traces.
- **Expert Registry:** Configuration and management of active AI experts.
- **Decision Trace Explorer:** Immutable audit log viewer with detailed execution contexts.
- **Recommendation Center:** Actionable list of AI-generated insights and recommendations.

### 7. Review & Output
- **Human Review Center:** Interface for consultants to approve, reject, or modify AI decisions.
- **Report Center:** PDF/DOCX generation, template management, and export history.

### 8. Administration & Settings
- **User Management:** Invite, suspend, manage users.
- **Roles & Permissions:** Granular access control matrices.
- **System Monitoring:** Health metrics, API usage, memory usage.
- **Logs:** System, security, and application logs.
- **Settings:** Global preferences, theme, API keys.
- **Help Center:** Documentation, tutorials, support tickets.
