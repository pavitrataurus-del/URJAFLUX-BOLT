# END-USER-PORTAL-DESIGN
## URJAFLUX AI OS

### Purpose
The End-User Portal is for `Consultants`, `Engineers`, and `Reviewers`. It focuses on specific project execution, analysis, and report generation.

### Key Screens & Features

#### 1. Project Dashboard
- **Visuals:** Bento-grid of project health.
- **Metrics:** Total documents processed, Spatial intelligence score, Pending AI recommendations, Review completion %.
- **Actions:** Upload new documents, Export Final Report.

#### 2. Workspace (The Core Loop)
The unified interface for analyzing a specific building or site.
- **Canvas:** Central area for floor plans (Digital Twin).
- **Context Panel:** Depending on selection, shows Document text, Knowledge Graph nodes, or AI recommendations relevant to the selected spatial element.

#### 3. Review Center
- **Visuals:** Split-screen interface. Left side shows the AI's recommendation and logic trace. Right side shows the spatial context or document evidence.
- **Actions:** Keyboard-friendly approval flow (e.g., `Cmd+Enter` to Approve, `Cmd+Backspace` to Reject).

#### 4. Knowledge Library
- **Visuals:** File explorer interface.
- **Data:** PDFs, CAD files, generated ontologies.
- **Features:** Semantic search bar ("Find all mentions of load-bearing walls in the structural annex").

#### 5. Report Builder
- **Visuals:** WYSIWYG editor combined with block-based components.
- **Features:** Drag and drop AI recommendations, spatial screenshots, and compliance scores into a branded template.
