# Truth Graph Engine Report

## Overview
The **Truth Graph Engine** renders network graph visualizers illustrating the full verification lineage of a knowledge rule.

## Node Taxonomy
- `RULE`: Central candidate rule.
- `SOURCE`: Supporting primary texts and manuscripts.
- `EVIDENCE`: Linked empirical findings and field observations.
- `EXPERT`: Reviewers and consensus voters.
- `CONTRADICTION`: Conflicting claims or alternative readings.

## Edge Relationships
Visualizes directional flows showing how sources feed evidence, experts vote on claims, and contradictions link opposing statements.
