# Evidence Management Engine Report

## Overview
The **Knowledge Evidence Engine** links primary scriptural sources, empirical measurements, case studies, and field observations to knowledge rules.

## Evidence Hierarchy
1. **Primary Sources**: Classical Sanskrit Shastras (e.g., *Mayamatam*, *Manasara*, *Brihat Samhita*, *Vishvakarma Prakash*).
2. **Empirical Measurements**: Geopathic stress readings, thermal imaging, and architectural surveys.
3. **Case Studies**: Real-world residential and commercial layout transformations.
4. **Field Observations**: SME on-site assessments and sensor telemetry data.

## Evidence Strength Calculation
`evidenceStrength` is dynamically computed from:
- Average reliability score of linked primary sources (60% weight).
- Quantity and diversity of supporting evidence items (40% weight).
