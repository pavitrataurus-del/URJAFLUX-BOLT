# DOMAIN-003 — Lal Kitab Admin & User Workspace Documentation

## Overview
The **Lal Kitab Workspace** (`LalKitabKnowledgeLibraryWorkspace.tsx`) is an interactive dashboard supporting end-to-end Lal Kitab knowledge exploration, manuscript management, conflict resolution, and quality auditing.

## Sub-Tab Modules
1. **Overview**: Metric summary showing total entities, canonical compliance percentage, active conflicts, and taxonomy distribution.
2. **Entity Browser**: Multi-faceted filter panel to search and inspect Grahas, Bhavs, Upays, Daan, Objects, Metals, Colors, and Conditional Rules.
3. **Knowledge Explorer**: Full-text and semantic search engine across all Lal Kitab manuscript fields.
4. **Source Manager (Admin)**: Detailed traceability panel displaying approved manuscript editions (1939 - 1952) and page-level provenance.
5. **Conflict Resolution (Admin)**: Workspace to resolve book-vs-book discrepancies and mark contextual rule splits (e.g., Mangal Neek vs Mangal Badd).
6. **Canonical Rules**: Clean card-based feed of verified rules with confidence grade badges (A+, A, B, C, F).
7. **Knowledge Graph**: Interactive node-edge visualizer mapping relationship links between planets, houses, remedies, metals, and spatial zones.
8. **Duplicate Detection & Quality Dashboard**: Quality score breakdown across OCR accuracy, source authority, SME consensus, and ontological completeness.
