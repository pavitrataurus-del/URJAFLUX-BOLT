# Extended Truth Graph Report

## Extended Node Types
Extends the base URJAFLUX Knowledge Graph with 7 specialized truth nodes:
1. `TRUTH_NODE`: Canonical Knowledge Statement.
2. `EVIDENCE_NODE`: Linked Manuscript Citation.
3. `SOURCE_NODE`: Scriptural Corpus Authority Record.
4. `CONSENSUS_NODE`: SME Acharya Sign-Off State.
5. `CONFIDENCE_NODE`: Dynamic Rating & Grade.
6. `DEPENDENCY_NODE`: Ontological Spatial Link.
7. `VERSION_NODE`: Edition & Translation History.

## Visualization
Integrated with interactive canvas viewer in `VerificationDashboard.tsx`.
